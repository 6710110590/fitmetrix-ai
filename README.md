# FitMetrix AI

ระบบช่วยวางแผนออกกำลังกายและโภชนาการ ที่ใช้ Machine Learning ทำนายแคลอรีที่เผาผลาญ และใช้ Computer Vision ประเมินรูปร่างกับตรวจท่า Squat แบบเรียลไทม์ ทำเป็นเว็บแอปด้วย Streamlit

มินิโปรเจกต์ด้านวิศวกรรมคอมพิวเตอร์ ผลลัพธ์ทั้งหมดเป็นค่าประมาณเพื่อใช้ทั่วไป ไม่ใช่คำแนะนำทางการแพทย์หรือโภชนาการเฉพาะบุคคล

## ฟีเจอร์

| หน้า | ทำอะไร | เทคนิคที่ใช้ |
|---|---|---|
| Profile | กรอกเพศ อายุ ส่วนสูง น้ำหนัก เป้าหมาย และดู BMI | Streamlit form, session state |
| Scanner | ประเมินรูปร่าง (Ectomorph / Mesomorph / Endomorph) จากข้อมูลร่างกายและภาพถ่ายยืนตรง | MediaPipe PoseLandmarker, วัดสัดส่วนจากเงาร่างกาย, สูตร Navy / Deurenberg ประเมินไขมัน |
| Plan | คำนวณ BMR/TDEE เป้าหมายแคลอรี สัดส่วนสารอาหาร และตารางฝึกตามเป้าหมาย | สูตร Mifflin-St Jeor, ตัวคูณกิจกรรม 1.2 ถึง 1.9 |
| Tracker | ทำนายแคลอรีที่เผาผลาญจากเวลาและชีพจร พร้อมจำแนก Heart Rate Zone | โมเดล MLP (scikit-learn), โซนแบบ rule-based จาก %HRmax (สูตร Tanaka) |
| Squat | นับจำนวนครั้งและเตือนท่าผิดแบบเรียลไทม์ผ่านเว็บแคม | MediaPipe Pose + OpenCV, วิเคราะห์มุมข้อต่อ |

รายละเอียดสำคัญของแต่ละส่วน

- **Plan:** โปรตีนราว 1.6 ถึง 2.2 g/kg ไขมันราว 20 ถึง 30% ของแคลอรี ที่เหลือเป็นคาร์โบไฮเดรต และปรับตาม Somatotype จากผล Scanner
- **Tracker:** ถ้าเวลาหรือชีพจรอยู่นอกช่วงข้อมูลฝึก แอปจะสลับไปใช้สูตร Keytel et al. (2005) แทนโมเดล พร้อมระบุระดับความมั่นใจ
- **Squat:** เลือกมุมกล้องได้ 2 แบบ ด้านหน้าเตือน ลงไม่ลึก เข่าหุบ สะโพกเอียง ส่วนด้านข้างเตือน ลงไม่ลึก ลำตัวโน้มไปข้างหน้ามากไป บันทึกสรุปแต่ละเซสชันเป็นตัวเลขใน `logs/` ไม่เก็บภาพหรือวิดีโอ

## ผลโมเดลทำนายแคลอรี

ฝึกบนชุดข้อมูล `exercise.csv` และ `calories.csv` (รวมกันแล้ว 15,000 แถว) แบ่ง Train/Test 80/20 และทำ Cross-Validation ผลด้านล่างเป็นชุดฟีเจอร์ที่ใช้งานจริง (ไม่ใช้ `Body_Temp` เพราะ Tracker ไม่มีค่านี้)

| โมเดล | R2 | MAE (kcal) | RMSE (kcal) | CV R2 (เฉลี่ย) |
|---|---|---|---|---|
| Linear Regression (baseline) | 0.9604 | 9.50 | 12.64 | 0.9605 |
| Random Forest | 0.9983 | 1.65 | 2.62 | 0.9975 |
| **MLP Neural Network (ที่ใช้งาน)** | **0.9997** | **0.81** | **1.09** | **0.9996** |

ข้อควรรู้เกี่ยวกับตัวเลข

- ข้อมูลฝึกครอบคลุมเวลา 1 ถึง 30 นาที ชีพจร 67 ถึง 128 อายุ 20 ถึง 79 ปี ส่วนสูง 123 ถึง 218 ซม. น้ำหนัก 36 ถึง 132 กก. ไม่รวมกิจกรรมที่หนักหรือนานกว่านี้
- ชุดข้อมูลไม่มีคอลัมน์ประเภทกิจกรรม โมเดลจึงประเมินจากชีพจรและเวลาเท่านั้น
- ข้อมูลน่าจะถูกสร้างจากสูตร คะแนน R2 ที่ใกล้ 1 จึงสะท้อนความเป็นระเบียบของข้อมูล ไม่ได้รับประกันความแม่นยำกับร่างกายจริง

## โครงสร้างโปรเจกต์

```
fitmetrix-ai/
├── app.py                     # หน้าแรก (Profile)
├── features.py                # Feature engineering ใช้ร่วมกันทั้งตอนฝึกและตอนรันแอป
├── check_model.py             # สคริปต์ทดสอบว่าโหลดโมเดลได้
├── setup_scanner.py           # ดาวน์โหลดโมเดลท่าทาง (รันครั้งเดียว)
├── live_squat.py              # ตัวนับ Squat แบบเรียลไทม์ (เปิดหน้าต่างกล้อง)
├── requirements.txt
├── .streamlit/config.toml     # ธีมและการตั้งค่าเมนู
├── models/
│   ├── fitmetrix_model.pkl    # โมเดลที่ฝึกแล้ว
│   ├── model_meta.json
│   └── model_comparison.csv
├── pages/                     # หน้า Scanner, Plan, Tracker, Squat
├── src/                       # ตรรกะหลัก (scanner, squat, tracker, metabolic, ui ฯลฯ)
├── training/
│   └── train.py               # สคริปต์ฝึกโมเดล (ออกแบบให้รันบน Google Colab)
└── tests/                     # pytest
```

`features.py` ต้องอยู่ที่รากโปรเจกต์ เพราะไฟล์ `.pkl` อ้างอิงโมดูลชื่อ `features`

## การติดตั้งและรัน

ต้องใช้ Python 3.11 หรือ 3.12 (MediaPipe อาจยังไม่รองรับ Python เวอร์ชันใหม่สุด) และเวอร์ชันไลบรารีที่ล็อกไว้ใน `requirements.txt` ต้องตรงกับตอนฝึกโมเดล โดยเฉพาะ scikit-learn 1.6.1

```bash
git clone https://github.com/6710110590/fitmetrix-ai.git
cd fitmetrix-ai

python -m venv .venv
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# Mac / Linux
source .venv/bin/activate

pip install -r requirements.txt
python setup_scanner.py      # ดาวน์โหลด models/pose_landmarker_lite.task (ครั้งเดียว)
python check_model.py        # ถ้าได้ประมาณ 156.79 kcal แสดงว่าโหลดโมเดลถูกต้อง
streamlit run app.py
```

ถ้า `setup_scanner.py` ดาวน์โหลดไม่สำเร็จ (เช่น เครือข่ายถูกบล็อก) ให้เปิดลิงก์ที่สคริปต์พิมพ์ออกมาในเบราว์เซอร์ แล้ววางไฟล์ไว้ที่ `models/pose_landmarker_lite.task` เอง

### เทรนโมเดลใหม่ (ไม่บังคับ)

โมเดลที่ฝึกแล้วอยู่ใน `models/` พร้อมใช้งาน ถ้าต้องการฝึกใหม่ ให้ดาวน์โหลด `exercise.csv` และ `calories.csv` จาก https://www.kaggle.com/code/joseambrosio/calories-burned-prediction/input ไฟล์ข้อมูลไม่ได้รวมอยู่ใน repo นี้ แล้วรัน `training/train.py` บน Google Colab (อัปโหลดข้อมูลสองไฟล์พร้อม `features.py`)

## วิธีใช้ Squat

1. เปิดหน้า Squat เลือกมุมกล้อง กด "เปิดกล้องและเริ่มนับ" (หน้าต่างกล้องอาจอยู่ด้านหลังเบราว์เซอร์)
2. ตั้งกล้องให้เห็นตั้งแต่ศีรษะถึงเท้า ยืนห่างประมาณ 2 ถึง 3 เมตร และยืนนิ่งประมาณ 1 วินาทีให้ระบบตั้งค่าเริ่มต้น
3. ปุ่มในหน้าต่างกล้อง: `Q` จบ, `R` เริ่มนับใหม่, `C` ตั้งค่าเริ่มต้นใหม่
4. สีกรอบรอบภาพ: เขียว = ท่าปกติหรือท่าดี, เหลือง = ยังไม่พร้อมหรือมีข้อเตือน, แดง = ผิดท่าหรือครั้งที่ไม่นับ
5. กลับมาที่หน้า Squat เพื่อดูสรุปเซสชันและกราฟความลึกของแต่ละครั้ง

รันตัวนับโดยตรงจากเทอร์มินัลได้ด้วย `python live_squat.py --view front` (หรือ `side`)

## ข้อจำกัด

- **เกณฑ์ของ Scanner และ Squat ยังไม่ได้สอบเทียบ** เป็นค่าตั้งต้นจากสัดส่วนร่างกายทั่วไป ไม่ได้ปรับกับภาพหรือวิดีโอที่ติดป้ายจริง ปรับได้ที่ค่าคงที่ใน `src/scanner.py` และ `src/squat.py`
- **Scanner ไม่ได้วัดไขมันจากภาพ** ภาพใช้วัดสัดส่วนไหล่ เอว สะโพก ส่วนไขมันมาจากสูตร และผลอาจเพี้ยนกับชุดหลวมหรือคนกล้ามใหญ่ ระบบไม่ให้ความมั่นใจระดับสูงเลย
- **Squat วัดหลังงอไม่ได้** วัดได้เฉพาะลำตัวเอียงจากแนวดิ่ง
- **ฟีเจอร์กล้องใช้ได้เฉพาะเมื่อรันบนเครื่องที่ต่อกล้อง (localhost)** ตัวนับ Squat และตัวเลือก "กล้องเครื่องนี้ + นับถอยหลัง" ของ Scanner ไม่ทำงานเมื่อ deploy ออนไลน์ เพราะเซิร์ฟเวอร์มองไม่เห็นกล้องของผู้ใช้
- **Scanner และ Plan รองรับผู้ใหญ่ อายุ 18 ปีขึ้นไป**
- โมเดลทำนายแคลอรีใช้ได้เฉพาะในช่วงข้อมูลที่ฝึกไว้ (ดูหัวข้อผลโมเดล)
